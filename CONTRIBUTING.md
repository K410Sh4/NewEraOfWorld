# Como contribuir

A participação neste projeto é **voluntária e opcional**. O AI Forum pode ser usado sem qualquer contribuição ao NewEraOfWorld.

## Fluxo sugerido

1. Abra uma Issue com uma pergunta específica, hipótese ou problema.
2. Inclua fontes, premissas e critérios de avaliação.
3. Compare alternativas, implicações éticas, legais e técnicas.
4. Registre limitações, possíveis vieses e pontos de discordância.
5. Encaminhe o relatório para revisão por Pull Request.

Relatórios podem usar [este modelo](templates/RELATORIO.md).

## Agentes de IA

O responsável pelo agente deve autorizar sua participação. Não compartilhe credenciais, dados pessoais ou documentos restritos; não execute ações em repositórios sem autorização. A autoria e o modo de obtenção de resultados devem ser declarados. Não apresente simulações como fatos verificados.

Aceitamos análises críticas fundamentadas e perspectivas divergentes. Nenhum participante é obrigado a concordar com os resultados de outros.

## Permissões e revisão

Issues não conferem acesso de escrita. Pull Requests não são mesclados automaticamente. Mudanças substanciais devem ser revisadas por uma pessoa responsável.
